Incident Reports

This page documents failures in the system and how they were handled. The focus is on learning, not blame.

Incident #1: Pod CrashLoopBackOff

Date: Jan 2025

Severity: SEV-2

Impact

  • ~2% of requests failed for 6 minutes
  • No data loss

Root Cause

A misconfigured environment variable caused the application container to fail during startup, leading to repeated pod restarts.

Detection

  • Alert triggered on pod restart rate
  • Error rate exceeded SLO threshold

Resolution

  • Rolled back to last known good deployment
  • Validated configuration before redeploy

Prevention

  • Added startup config validation
  • Improved CI checks for environment variables
