System Architecture

This system is designed as a small but production-realistic SRE platform on AWS. The goal is not complexity, but reliability, observability, and operational clarity.

High-Level Flow

  • User traffic enters through AWS Application Load Balancer (ALB)
  • Traffic is routed to Kubernetes services in Amazon EKS
  • Pods run stateless application containers
  • Metrics, logs, and traces are collected for observability

AWS Components

  • VPC – Network isolation across multiple availability zones
  • EKS – Managed Kubernetes control plane
  • EC2 Worker Nodes – Container execution
  • ALB Ingress Controller – External traffic routing
  • CloudWatch – Logs and basic metrics

Design Decisions

  • EKS chosen over ECS to demonstrate Kubernetes operational knowledge
  • Stateless workloads for easy scaling and recovery
  • Infrastructure managed using Terraform to ensure repeatability
